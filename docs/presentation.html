Hardware approval for AI agents

GATEKEEPER

The one screen your AI can't lie to.
The problem

AI agents can be hijacked — and you'd approve it without knowing.

  • Agents now send email, delete files, and move money.
  • They read untrusted content — emails, invoices — that can carry hidden instructions.
  • The confirmation lives on the same screen the attacker controls, so a dangerous action looks harmless.
The solution

Put the real action on a screen the software can't touch.

  • The agent can only ask. Nothing happens until a separate device shows the true recipient, file, or amount.
  • A human approves physically: a button hold, plus an RFID card tap for payments over $500.
  • The device signs the verdict with an Ed25519 key that never leaves the hardware.
How it works

The host can lie. It can't forge a signature.
